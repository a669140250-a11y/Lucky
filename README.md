# 🍀 Lucky 抽一下

现代、活泼风格的随机抽签 WebApp。不知道现在要干嘛？聚会冷场？交给 Lucky 抽一张！

## ✨ 功能

### ☀️ 现在干嘛（单人日常灵感）
- 按“抽一张”，随机抽出一张日常微任务卡（深呼吸、整理抽屉、发消息给老朋友…）
- 每张卡片都有分类标签（放松、动一动、创意、整理、社交、学习、小确幸、探索）和预估时间
- 做完按“完成了！”会盖章、喷彩带，并累计完成数

### 🎉 真心话大冒险（多人聚会）
- 先选 **💬 真心话** 或 **🔥 大冒险**，再选尺度 **🌱 普通** 或 **🌶️ 进阶**
- 按“翻牌！”（或直接点卡片）会用 3D 翻牌动画揭晓题目
- 换类型或尺度时，牌会自动翻回背面

### 📝 自定义题库
- 右上角“自定义题库”可以替 **现在干嘛 / 真心话 / 大冒险（普通、进阶）** 添加自己的题目
- **一行一题**，可以一次粘贴很多题；重复的题目会自动跳过
- 删除或清空后可以按“撤销”救回来
- “只抽我的自定义题目”开关：打开后只从自定义题库抽（该分类没有自定义题目时会先用内置题库）
- 导出 / 导入 JSON 备份，方便换手机或分享给朋友

### 其他小细节
- 洗牌袋抽法：同一组题目全部抽过一轮之前不会重复
- 手机优先设计，支持添加到主屏幕（PWA manifest）
- 支持“减少动态效果”系统设置、键盘操作与屏幕阅读器提示

## 🚀 使用方式

纯前端、免安装、免构建：

- **直接打开**：用浏览器打开 `index.html` 就能玩
- **本地服务器**：`python3 -m http.server 8000`，再开 <http://localhost:8000>
- **GitHub Pages**：Settings → Pages → Source 选 `main` 分支根目录，几分钟后就有公开网址

> 自定义题目存在浏览器的 localStorage，只会留在这台设备、这个浏览器里。清除浏览数据前记得先“导出备份”。

## 📁 文件结构

```
index.html            页面结构
css/style.css         样式与动画
js/data.js            内置题库（想改内置题目就改这里）
js/app.js             抽签、翻牌、自定义题库等交互逻辑
manifest.webmanifest  PWA 设置
icons/                App 图标
```

## 🧩 扩充内置题库

打开 `js/data.js`，照格式加一行即可：

```js
// 现在干嘛：e = emoji、t = 任务内容、c = 分类、m = 预估分钟
{ e: '🍦', t: '去便利店买一样从没吃过的零食', c: '探索', m: 10 },

// 真心话 / 大冒险：直接加字符串
truth: { normal: ['你最近一次大笑是因为什么事？', ...], advanced: [...] }
```

## 导出文件格式

```json
{
  "app": "lucky",
  "version": 1,
  "bank": {
    "daily": ["自定义任务…"],
    "truth": { "normal": [], "advanced": [] },
    "dare":  { "normal": [], "advanced": [] }
  }
}
```

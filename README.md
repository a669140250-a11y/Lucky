# 🍀 Lucky 抽一下

現代、活潑風格的隨機抽籤 WebApp。不知道現在要幹嘛？聚會冷場？交給 Lucky 抽一張！

## ✨ 功能

### ☀️ 現在幹嘛（單人日常靈感）
- 按「抽一張」，隨機抽出一張日常微任務卡（深呼吸、整理抽屜、傳訊息給老朋友…）
- 每張卡片都有分類標籤（放鬆、動一動、創意、整理、連結、學習、小確幸、探索）和預估時間
- 做完按「完成了！」會蓋章、噴彩帶，並累計完成數

### 🎉 真心話大冒險（多人聚會）
- 先選 **💬 真心話** 或 **🔥 大冒險**，再選尺度 **🌱 普通** 或 **🌶️ 進階**
- 按「翻牌！」（或直接點卡片）會用 3D 翻牌動畫揭曉題目
- 換類型或尺度時，牌會自動翻回背面

### 📝 自訂題庫
- 右上角「自訂題庫」可以替 **現在幹嘛 / 真心話 / 大冒險（普通、進階）** 新增自己的題目
- **一行一題**，可以一次貼上很多題；重複的題目會自動略過
- 刪除或清空後可以按「復原」救回來
- 「只抽我的自訂題目」開關：開啟後只從自訂題庫抽（該分類沒有自訂題目時會先用內建題庫）
- 匯出 / 匯入 JSON 備份，方便換手機或分享給朋友

### 其他小細節
- 洗牌袋抽法：同一組題目全部抽過一輪之前不會重複
- 手機優先設計，支援加到主畫面（PWA manifest）
- 支援「減少動態效果」系統設定、鍵盤操作與螢幕閱讀器提示

## 🚀 使用方式

純前端、免安裝、免建置：

- **直接開啟**：用瀏覽器打開 `index.html` 就能玩
- **本機伺服器**：`python3 -m http.server 8000`，再開 <http://localhost:8000>
- **GitHub Pages**：Settings → Pages → Source 選 `main` 分支根目錄，幾分鐘後就有公開網址

> 自訂題目存在瀏覽器的 localStorage，只會留在這台裝置、這個瀏覽器裡。清除瀏覽資料前記得先「匯出備份」。

## 📁 檔案結構

```
index.html            頁面結構
css/style.css         樣式與動畫
js/data.js            內建題庫（想改內建題目就改這裡）
js/app.js             抽籤、翻牌、自訂題庫等互動邏輯
manifest.webmanifest  PWA 設定
icons/                App 圖示
```

## 🧩 擴充內建題庫

打開 `js/data.js`，照格式加一行即可：

```js
// 現在幹嘛：e = emoji、t = 任務內容、c = 分類、m = 預估分鐘
{ e: '🍦', t: '去便利商店買一樣從沒吃過的零食', c: '探索', m: 10 },

// 真心話 / 大冒險：直接加字串
truth: { normal: ['你最近一次大笑是因為什麼事？', ...], advanced: [...] }
```

## 匯出檔格式

```json
{
  "app": "lucky",
  "version": 1,
  "bank": {
    "daily": ["自訂任務…"],
    "truth": { "normal": [], "advanced": [] },
    "dare":  { "normal": [], "advanced": [] }
  }
}
```
